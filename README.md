# বিজয় টাইপিং টিউটর (Bijoy Typing Tutor)

বিজয় কীবোর্ড লেআউটে **বাংলা টাচ টাইপিং** শেখার বিনামূল্যের ওয়েব অ্যাপ। সরকারি চাকরির বাংলা টাইপিং পরীক্ষার প্রস্তুতির জন্য তৈরি।
কোনো ইনস্টল, সার্ভার বা অ্যাকাউন্ট লাগে না — শুধু ব্রাউজার আর কম্পিউটারের কীবোর্ড।

## কী কী আছে

- **১৬টি পাঠ**: হোম রো → উপরের/নিচের সারি → শিফট → কার ও স্বরবর্ণ → যুক্তাক্ষর → সংখ্যা ও চিহ্ন → অনুচ্ছেদ
- **প্রতি পাঠে ৮টি করে অনুশীলনী** (নতুন কী, জোড়া, মিশ্র, শব্দ, বাক্য, গতি, চ্যালেঞ্জ…)। শব্দ সবসময় নতুন করে এলোমেলোভাবে তৈরি হয়
- **অন-স্ক্রিন কীবোর্ড**: কোন কী, কোন আঙুল, কখন Shift — রং করে দেখায়
- **গতি পরীক্ষা**: ১/২/৩/৫/১০ মিনিট, ৪ ধরনের লেখা, WPM + নির্ভুলতা + সবচেয়ে বেশি ভুল হওয়া কী
- **অগ্রগতি**: তারা (★), সেরা গতি, দৈনিক ধারাবাহিকতা, চার্ট, ব্যাকআপ ডাউনলোড/ফেরানো
- ডার্ক মোড, মোবাইল-ফ্রেন্ডলি লেআউট, কোনো ট্র্যাকিং নেই (সব ডেটা শুধু ব্রাউজারে)

## নিজের কম্পিউটারে চালানো

ফোল্ডারটি খুলে `index.html` ব্রাউজারে ডাবল-ক্লিক করুন। ব্যস।

## GitHub Pages-এ প্রকাশ (লিংক শেয়ার করার জন্য)

1. [github.com](https://github.com)-এ অ্যাকাউন্ট খুলুন → **New repository** → নাম দিন, যেমন `bijoy-typing` → **Public** → Create।
2. এই ফোল্ডারের সব ফাইল রিপোজিটরিতে আপলোড করুন (**Add file → Upload files**, তারপর Commit)।
   অথবা টার্মিনালে:
   ```bash
   git init
   git add .
   git commit -m "Bijoy typing tutor"
   git branch -M main
   git remote add origin https://github.com/আপনার-ইউজারনেম/bijoy-typing.git
   git push -u origin main
   ```
3. রিপোজিটরিতে **Settings → Pages** → *Source*: **Deploy from a branch** → Branch: `main`, folder: `/ (root)` → **Save**।
4. ১–২ মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/bijoy-typing/` — এটাই বন্ধুদের শেয়ার করুন।
5. (ঐচ্ছিক) `js/app.js`-এর শুরুতে `CONFIG.REPO_URL`-এ আপনার রিপোজিটরির লিংক বসান, তাহলে অ্যাপের নিচে "GitHub-এ দেখুন" লিংক আসবে।

## ⚠ কী-পজিশন মিলিয়ে নিন (গুরুত্বপূর্ণ)

বিজয় লেআউটের **ব্যঞ্জনবর্ণ, কার, স্বরবর্ণ (G কী), যুক্তাক্ষর (G), র-ফলা (Z)** সরকারি শিক্ষক বাতায়নের বিজয় টাইপিং শিট থেকে মিলিয়ে নেওয়া হয়েছে।
কিন্তু কিছু কম ব্যবহৃত কী নির্ভরযোগ্য সূত্রে মেলানো যায়নি, তাই আপনার ব্যবহৃত বিজয় বায়ান্ন/বিজয় ইকুশে-তে একবার মিলিয়ে দেখুন:

| চিহ্ন | অ্যাপে ধরা আছে |
| --- | --- |
| রেফ (র্) | Shift + A |
| ৌ-কার (ৗ অংশ) / ঔ | Shift + X |
| ঁ (চন্দ্রবিন্দু) | Shift + ৭ |
| ঃ (বিসর্গ) | ` (১-এর বাঁয়ে) |
| ৎ (খণ্ড ত) | Shift + ` |
| ৳ | Shift + ৪ |
| য-ফলা / ব-ফলা | G + W / G + H (হসন্ত দিয়ে) |

কোনোটা আপনার কীবোর্ডে অন্য জায়গায় থাকলে **শুধু `js/layout.js`-এর `MAP` তালিকায় সেই লাইনটি বদলান** — পাঠ, কীবোর্ড ও কনভার্টার সব নিজে থেকে ঠিক হয়ে যাবে।
`node tests/run.js` চালিয়ে দেখে নিন সব ঠিক আছে কিনা। ভুল পেলে Issue বা Pull Request দিন, সবাই উপকৃত হবে।

## প্রকল্পের গঠন

```
index.html        পাতার কাঠামো
css/style.css     ডিজাইন
js/layout.js      বিজয় কী-পজিশন + আঙুলের ম্যাপ  ← কী বদলাতে এটি দেখুন
js/converter.js   Unicode বাংলা → বিজয় কী-সিকোয়েন্স (কার আগে/পরে, যুক্তাক্ষর, রেফ…)
js/words.js       অনুশীলনের শব্দ ও বাক্য         ← নতুন শব্দ যোগ করুন
js/passages.js    গতি পরীক্ষা ও অনুচ্ছেদ         ← নতুন অনুচ্ছেদ যোগ করুন
js/lessons.js     পাঠ-তালিকা ও অনুশীলনী তৈরি
js/app.js         অ্যাপ (টাইপিং ইঞ্জিন, পাতা, অগ্রগতি)
tests/run.js      স্বয়ংক্রিয় পরীক্ষা (node tests/run.js)
```

## অবদান রাখুন

নতুন শব্দ/অনুচ্ছেদ, ভুল সংশোধন বা নতুন সুবিধা — Pull Request স্বাগত।
শব্দ যোগ করার পর `node tests/run.js` চালান; এটি দেখে নেয় প্রতিটি শব্দ কনভার্ট হয় এবং কোনো পাঠে অশেখা কী আসছে না।
